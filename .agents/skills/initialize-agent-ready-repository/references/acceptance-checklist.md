# Akceptační checklist nového repozitáře

- [ ] Hlavní `README.md` vysvětluje účel a rychlý start.
- [ ] `AGENTS.md` obsahuje společná pravidla, ne kopii celé dokumentace.
- [ ] `docs/agent-context/README.md` vysvětluje znalostní vrstvu.
- [ ] `.agents/profiles/README.md` vysvětluje kanonické profily.
- [ ] `.agents/skills/README.md` vysvětluje skills.
- [ ] `toolkit/README.md` vysvětluje jediný kořen všech exaktních nástrojů a jejich podsložky; `.agents/tools`, kořenové `tools` ani skillové `scripts` neexistují.
- [ ] `resources/README.md` vysvětluje účel, původ, licenci a autoritativnost analyzovaných vstupů, i když zatím žádné nejsou přidány.
- [ ] Neexistují dvě autoritativní kopie stejné informace.
- [ ] Platformní konektor vznikl pouze na přání nebo podle jednoznačně aktuálního prostředí Codex.
- [ ] Platformní soubory jsou tenké a označené, pokud jsou generované.
- [ ] Codex konektor nepřidává zbytečné soubory; ostatní konektory bez požadavku nevznikly.
- [ ] V repozitáři nejsou credentials nebo lokální osobní nastavení.
- [ ] Všechny známé příkazy lze spustit nebo jsou označené jako `TODO`.
- [ ] Validace architektury skončila bez chyb.
