# Agent profiles

Tato složka obsahuje kanonické profily v projektovém neutrálním formátu `<name>.agent.md`.

Profily se neupravují v platformních složkách. Platformní varianty se vytvářejí pomocí `toolkit/agent-infrastructure/render_platform_connectors.py` nebo skillu `add-platform-connector`.

Formát je popsán v `docs/agent-context/profile-schema.md`.
