# Epic: authoring-repository

## Cíl

Zavést a dlouhodobě udržovat autoritativní model authoring repozitářů v
Repository-helperu a řídit jeho postupné použití v Orchestrátoru, XDS a dalších
authoring vrstvách.

## Rozsah

- taxonomie primárních typů repozitářů;
- capability, skill, produktová šablona a strukturální validace authoringu;
- specializovaná a orchestrační role;
- navazující standard registrů, kompatibility a release evidence.
