# Projektová dokumentace

Tato složka drží kurátorovanou stopu konkrétní klientské implementace.

- `assignment.md` je živé zadání a stav jeho potvrzení.
- `analysis/` obsahuje ověřené závěry, rizika a otevřené body.
- `design/` obsahuje informační architekturu, layouty a odkazy na jejich zdroj.
- `client/` obsahuje pouze potvrzená rozhodnutí a akceptaci, ne necenzurovanou komunikaci.
- `traceability.md` propojuje požadavky, doménu, implementaci a ověření.
- `offers/` je volitelná capability pro klientské HTML nabídky; není součástí každého klientského projektu.
