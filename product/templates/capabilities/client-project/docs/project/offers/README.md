# Nabídky

Tato volitelná složka vede kurátorovanou stopu klientských nabídek. Každá nabídka má adresář `<offer-id>/` s manifestem `README.md`, analýzou, návrhem, akceptací a trasovatelností. Původní podklady patří do `resources/offers/<offer-id>/`; publikovat lze výhradně `public/offers/<offer-id>/`.

Podrobnosti, stavové modely a publikační kontrakt jsou v `docs/agent-context/client-offers-capability.md`.
