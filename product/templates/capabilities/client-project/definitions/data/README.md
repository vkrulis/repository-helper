# Definice — data

Aplikační a doménová data napojená na projektový definiční model: číselníky, role,
historie, registry a obdobné podklady, na které se definiční model (XDS) odkazuje za
běhu aplikace. Ukládejte jen podklady patřící ke skutečné implementaci projektu, ne
obecné vzory nebo cizí zákaznická data.
