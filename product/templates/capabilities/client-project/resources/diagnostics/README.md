# Diagnostické vstupy

Ukládejte sanitizované logy, exporty, snímky a další analyzovatelné důkazy. Zapište jejich
původ, časové období, nástroj vytvoření, citlivost a zda jde o úplný nebo redukovaný vzorek.
Závěry z diagnostiky patří do analytické autority projektu: v Project Memory do příslušného
`project/epics/EPIC-NNNN/`, v helper-native layoutu do `docs/project/analysis/` nebo
`docs/agent-context/`. Syrový diagnostický vstup není sám o sobě potvrzeným závěrem.
