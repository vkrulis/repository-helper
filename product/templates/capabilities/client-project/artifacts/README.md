# Odvozené artefakty

Sem patří reprodukovatelné výstupy kompletace, validace, replikace nebo předání. V README a
`.gitignore` projektu výslovně rozhodněte, které artefakty se necommitují, které se verzují jako
důkaz vydání a jak je lze znovu vytvořit. Nevydávejte generovaný obsah za ručně spravovaný zdroj.
