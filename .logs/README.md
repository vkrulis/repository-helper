# Pracovní historie

Tato složka obsahuje kanonickou chronologickou historii materiálních prací v repozitáři.

- Denní soubor má cestu `.logs/YYYY/MM/YYYY-MM-DD.md`.
- Záznamy se přidávají; pozdější změna závěru vytváří nový záznam místo přepsání historie.
- Záznam stručně uvádí výsledek, změněné soubory, validaci a případnou navazující práci.
- Aktuální autoritativní znalost patří do `docs/agent-context/`, nikoli do logu.
- Fyzickou historii změn uchovává Git.
- Do logu nepatří secrets, osobní či produkční data, skryté uvažování ani celé výpisy nástrojů.

Záznamy vytvářejte a ověřujte pomocí `toolkit/work-log/work-log.py`.
