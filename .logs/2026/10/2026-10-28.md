# Pracovní log — 2026-10-28

## Project documentation capability
- Typ: architecture / skill / tooling
- Stav: done
- Scope: shared

### Shrnutí

Zavedena přenositelná capability `project-documentation` pro aktuální dokumentaci klientské
Flexideo aplikace. Model odděluje `docs/` od analytických epiků Project Memory a propojuje
XDS/FDT/DAD, intranetové x-item/settings, akce/procesy a COMEX UI. Do Project Memory se
instaluje pouze skill, reference a read-only nástroj; helper nepřebírá provisioning ani
sémantické zápisy.

### Zdrojové podklady

Použity byly aktuálně dostupné GitHub zdroje Orchestrátoru, Replicatoru, XDS veřejné
definition-driven dokumentace a Intranet authoringu. Uživatelův lokální soubor
`client-application-documentation-proposal.md` nebyl v připojených GitHub větvích ani
Project souborech dostupný; proto do této změny nejsou vydávány za převzaté žádné jeho
nedostupné konkrétní formulace. Model je připraven na následné přesné sladění.

kompatibility, validaci skill kolekce, repository architecture a work logu.
