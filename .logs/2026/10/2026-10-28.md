## Project documentation capability
- Typ: architecture / skill / tooling
- Stav: done
- Scope: shared

### Shrnutí

Zavedena přenositelná capability `project-documentation` pro aktuální dokumentaci klientské
Flexideo aplikace. Model odděluje `docs/` od analytických epiků Project Memory a propojuje
XDS/FDT/DAD, intranetové x-item/settings, akce/procesy a COMEX UI. Do Project Memory se
instaluje pouze skill, reference a read-only nástroj; helper nepřebírá provisioning ani
sémantické zápisy.

### Výsledek revize

Původní capability byla významově správná, ale příliš hrubá. Doplněny byly zejména:

- oddělené kurátorované `docs/` versus odvozené technické reference;
- přesné proposal-stage rodiny `reference/application`, `comex`, `usage`, `indexes`;
- detailní karty složek, přehledů/sloupců, UI tools, akcí, procesů, projekcí, COMEX
  stránek/komponent/modifikátorů a šablon;
- stabilní identity, typed relations a evidence každé hrany;
- obousměrné FDT ↔ application ↔ COMEX dotazy;
- coverage, refresh/invalidace nezávislá na replikaci a pravidlo „nenalezeno není nepoužito“;
- mapování pracovního `docs/agent-context/application` návrhu do Project Memory
  `docs/aplikace/funkce` a `docs/aplikace/scenare`.
