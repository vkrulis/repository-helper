# Authoring product

Tento strom je jediným autoritativním zdrojem publikovatelného authoring produktu.
Popište jeho roli (`specialist` nebo `orchestrator`), podporované vrstvy, verzi,
kompatibilitu, build, test a způsob publikace.

- Produktové skills: `skills/`
- Sdílené produktové nástroje: `tools/`
- Kontrakty a registry: `contracts/`
- Release testy a evaly: `tests/`
