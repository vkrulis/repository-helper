# Podklady nabídek

Každá nabídka má `resources/offers/<offer-id>/` se složkami `meetings/`, `client-files/`, `images/` a `references/`, každou s vlastním README nebo manifestem. Evidujte `source`, `received_at`, `owner`, `format`, `usage_rights`, `sensitivity`, `authoritative` a `related_offer_sections`.

Podklady nejsou automaticky publikovatelné. Neukládejte secrets ani osobní či produkční data bez výslovného oprávnění.
